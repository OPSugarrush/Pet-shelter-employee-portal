# REST API & Pet Shelter Portal

A Node.js/Express REST API and web application for managing pets across multiple animal shelters. The portal is designed from the perspective of a shelter employee, allowing users to view and manage pet records and move animals between shelters.

## Features

* View pet information and shelter records
* Add and update pets
* Move pets between shelters
* Filter and retrieve pets from structured JSON data
* Validate requests and maintain data-integrity rules
* Handle invalid inputs, missing data and HTTP errors
* Automated API testing with Jest and Supertest
* Endpoint testing and documentation with Postman

## Technologies

**Node.js, Express, JavaScript, HTML/CSS, REST, JSON, Jest/Supertest, Postman**

The underlying API was also structured for potential reuse in other domains, including a hotel-booking application.
